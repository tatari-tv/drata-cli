# [](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events)Events

Events record the activity of User and automated processes in the Drata platform.

## [](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents)List Events

Find Events matching the provided filters.

🔒 Requires **Event Tracking: List Events** permission.

Security**bearer** or **oauth2**

Request

##### query Parameters

[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=cursor&t=request)cursor string

This parameter is used to paginate through results. No value is needed for the first request. If there are additional results, the response will contain a `pagination.cursor` value that can be used in the subsequent request to retrieve the next page of results
[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=size&t=request)size number[ 1 .. 500 ]

Default:50

Number of results to return
[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=sort&t=request)sort string (EventSortTypeLimitedEnum)

Events can only be sorted by create date

Value:"createdAt"
[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=sortDir&t=request)sortDir string (SortDirectionEnum)

The direction to sort the data

Enum:"ASC""DESC"
[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=includeTotalCount&t=request)includeTotalCount boolean

Include total count of all matching records in response. Only honored on first page (when cursor is null).

Example:includeTotalCount=false
[](https://developers.drata.com/openapi/reference/v2/tag/Events/#tag/Events/operation/EventsPublicV2Controller_listEvents!in=query&path=expand[]&t=request)expand[]Array of strings (EventExpandEnum)

List of subcollections and sub-objects to expand

Items Enum:"connection""issues""metadata""testId""testName""user"
