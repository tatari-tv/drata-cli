# [](https://developers.drata.com/openapi/reference/v2/tag/Audit-Requests/#tag/Audit-Requests)Audit Requests

Audit Requests are the evidence requests that make up an Audit. Each request tracks its status, the Users assigned to it, and the evidence submitted against it.

## [](https://developers.drata.com/openapi/reference/v2/tag/Audit-Requests/#tag/Audit-Requests/operation/AuditRequestDcfSuggestionsPublicV2Controller_generateDcfSuggestions)Generate Audit Request DCF Suggestions 🧪

Starts DCF suggestion generation for each audit request and returns without waiting for it to finish. Each row reports whether a run was STARTED, SKIPPED (a run is already in progress) or FAILED to start. To track progress, list the audit requests (GET .../audits/:auditId/requests) or get one (GET .../audits/:auditId/requests/:requestId) with `expand[]=dcfSuggestionsSummary` and read `generationStatus`, or get the audit (GET .../audits/:auditId) with the same expand and wait for `requestsGeneratingCount` to reach 0.
