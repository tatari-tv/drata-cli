# [](https://developers.drata.com/openapi/reference/v2/tag/Users-and-Roles/#tag/Users-and-Roles)Users and Roles

**Users** are are people with access to the Drata platform.
**Roles** grant permissions to Users. The [help docs](https://help.drata.com/en/collections/5993507) have more information on the default Roles.

## [](https://developers.drata.com/openapi/reference/v2/tag/Users-and-Roles/#tag/Users-and-Roles/operation/RolesPublicV2Controller_listRoles)List Roles

Find Roles matching the provided filters.

🔒 Requires **Roles: List Roles** permission.

Security**bearer** or **oauth2**

Request
