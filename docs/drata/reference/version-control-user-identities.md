# [](https://developers.drata.com/openapi/reference/v2/tag/Version-Control-User-Identities/#tag/Version-Control-User-Identities)Version Control User Identities

Version Control User Identities are the external accounts your version control providers report, linked to Drata Users. Use the actions endpoint to link or unlink a User, to mark an identity a service account, and to acknowledge or retract write and production code push access. Acknowledging access records that it is approved, which clears the matching monitoring test. Infrastructure accounts are documented separately under Infrastructure User Identities.
