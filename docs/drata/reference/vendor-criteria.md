# [](https://developers.drata.com/openapi/reference/v2/tag/Vendor-Criteria/#tag/Vendor-Criteria)Vendor Criteria

Vendor Criteria are the reusable assessment criteria evaluated during a Vendor Security Review. Each criterion carries a type, a severity, the vendor types it applies to (empty means all), and an optional questionnaire file.

## [](https://developers.drata.com/openapi/reference/v2/tag/Vendor-Criteria/#tag/Vendor-Criteria/operation/VendorCriteriaPublicV2Controller_listVendorCriteria)List Vendor Criteria

Find vendor assessment criteria matching the provided filters.

🔒 Requires **Vendors: List Vendor Criteria** permission.

💎 Requires your account have the **TPRM Agentic Assessment, AI Data Share** feature. Contact your Account Manager for help upgrading.

🔒 Requires the company's **AI features** setting turned on. Otherwise it returns 403 `AI_FORBIDDEN`.

Security**bearer** or **oauth2**

Filter Criteria by Security Review ID: returns the Criteria selected for this Security Review. When none have been selected, returns the Criteria the review will assess, chosen from the Vendor's impact level, risk level and Vendor Type; those are always published, so pairing this with `isDraft=true` returns no rows. Returns 404 when the Security Review does not exist.
