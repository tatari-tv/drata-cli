# [](https://developers.drata.com/developer-portal/v2/skills/#agent-skills-beta)Agent Skills (Beta)

**🧪 Beta Feature:** Skills are available alongside the [MCP Server](https://developers.drata.com/developer-portal/v2/mcp-server/), which is currently in early access.

Skills are packaged workflows for AI assistants connected to your Drata account through the Drata MCP server. Each one is named for the job it does: **report** to see where you stand, **identify-gaps** to get a worklist of what needs work, and **resolve-gaps** to make the changes.

Install once, then run a skill by name or just ask for it in your own words.

Copy

Copied

```bash
/plugin marketplace add drata/drata-claude-plugin
/plugin install drata-grc-skills@drata
```

> **Read-only by default.** Most skills only read. 4 skills can change your Drata data and are marked **Write**: [Fix controls](https://developers.drata.com/developer-portal/v2/skills/compliance-and-audit-readiness/drata-control-resolve-gaps), [Fix evidence](https://developers.drata.com/developer-portal/v2/skills/compliance-and-audit-readiness/drata-evidence-resolve-gaps), [Fix risks](https://developers.drata.com/developer-portal/v2/skills/risk-management/drata-risk-resolve-gaps), [Fix vendors](https://developers.drata.com/developer-portal/v2/skills/third-party-and-vendor-risk/drata-vendor-resolve-gaps). One more can make a single write only when you confirm it: [Vendors needing review](https://developers.drata.com/developer-portal/v2/skills/third-party-and-vendor-risk/drata-vendor-identify-gaps). Every change is previewed for your confirmation before it is applied, and what any skill can reach is bounded by the scopes you grant and your Drata role.
>
>
> **One install, one grant.** Installing the plugin brings all 18 skills, and you authorise the Drata MCP server once — so the scopes you grant are the **union** of what every skill needs (27 scopes, 11 of them writes), not a per-skill choice. The tables on each page tell you what that skill uses, not what you can grant it alone.

## [](https://developers.drata.com/developer-portal/v2/skills/#connect-to-drata)Connect to Drata

The skills authenticate through the [Drata MCP Server](https://developers.drata.com/developer-portal/v2/mcp-server/) over OAuth — nothing stores a credential. You need **administrator access** to create the OAuth configuration in **Settings → MCP Configuration**, then point your client at the endpoint for your region:

*   **US:**
```text
https://mcp.drata.com/mcp/
```
*   **EU:**
```text
https://mcp-euc1.drata.com/mcp/
```
*   **APAC:**
```text
https://mcp-apse2.drata.com/mcp/
```

## [](https://developers.drata.com/developer-portal/v2/skills/#privacy)Privacy

The skills operate on your own Drata data, in your session, through your own OAuth grant. The plugin repository holds only natural-language prompts and a pointer to the Drata MCP endpoint — no customer data, no credentials, and no Drata backend code. Your data is handled under Drata's [privacy policy](https://drata.com/privacy); for how Drata secures its platform, see the [Trust Center](https://trust.drata.com/).
