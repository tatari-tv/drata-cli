# Get accounts

get

https://app.safebase.io/api/ext/v1/rest/accounts

Gets all accounts that match the given criteria.

Five filter query parameters can be sent and they work with an 'AND' relationship:

1.   Account name
2.   Member email
3.   Domain name
4.   Sfdc Account Id
5.   Review Status

The following query parameters are optional and can be used to control the sorting and pagination of the results:

*   Sort Field
*   Sort Direction
*   Page Number
*   Page Size

[](https://docs.safebase.io/reference/getaccounts#query-params)Query Params

name

string

[](https://docs.safebase.io/reference/getaccounts#query-params-name)

This parameter will search for an account that has the given name.

member

string

[](https://docs.safebase.io/reference/getaccounts#query-params-member)

This parameter will search for all accounts that contain a given member email.

domain

string

[](https://docs.safebase.io/reference/getaccounts#query-params-domain)

This parameter will search for all accounts that contain at least one member email with the given domain name.

Domain examples: safebase.io, example.com

sfdcAccountId

string

[](https://docs.safebase.io/reference/getaccounts#query-params-sfdcAccountId)

Salesforce Account Id to verify and get account

reviewStatus

string

[](https://docs.safebase.io/reference/getaccounts#query-params-reviewStatus)

One or more review statuses to filter accounts by.

sortField

string

enum

[](https://docs.safebase.io/reference/getaccounts#query-params-sortField)

The field to sort the results by.

Allowed:

`lastSeen`

sortDirection

string

enum

[](https://docs.safebase.io/reference/getaccounts#query-params-sortDirection)

The direction to sort the results by.

Allowed:

`asc``desc`

pageNumber

integer

1 to 500

[](https://docs.safebase.io/reference/getaccounts#query-params-pageNumber)

The page number to retrieve.

pageSize

integer

1 to 100

[](https://docs.safebase.io/reference/getaccounts#query-params-pageSize)

The number of results to return per page.
